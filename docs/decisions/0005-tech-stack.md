# 0005 – הכלים: Next.js, TypeScript, Tailwind, Supabase, Vercel

**סטטוס**: התקבלה · **תאריך**: 2026-11-24

## הקשר
אתר אמיתי לתיק עבודות, שעובד טוב בטלפון, עם התחברות, הרשאות וסנכרון בזמן אמת – בלי לשלם על שום שירות.

## ההחלטה
| שכבה | כלי | למה |
|---|---|---|
| מסגרת | **Next.js 16** (App Router) | צד לקוח וצד שרת באותו פרויקט; Server Components; נפרס בקלות ל־Vercel. |
| שפה | **TypeScript** במצב strict | טיפוסים כמו בג'אווה – הקומפיילר תופס שגיאות לפני הריצה. |
| עיצוב | **Tailwind CSS 4** | מחלקות קטנות ישירות ב־JSX, בלי קובצי CSS נפרדים לכל רכיב. יש מחלקות לוגיות (`ms-`, `me-`, `ps-`) שמתהפכות אוטומטית בימין־לשמאל. |
| צד שרת ומסד | **Supabase** | Postgres + התחברות + RLS + זמן אמת + אחסון, במסלול חינמי. ראה `docs/concepts.md`. |
| אחסון האתר | **Vercel** | פריסה אוטומטית מגיטהאב, תצוגה מקדימה לכל Pull Request, מסלול חינמי. |
| מנהל חבילות | **npm** | מגיע עם Node; אין צורך בכלי נוסף. |
| גופן | **Heebo** | תומך בעברית ובאנגלית; זה גם הגופן של האפליקציה הקיימת. |

## חלופות שנדחו
- **צד שרת נפרד (Spring Boot)**: מוכר מג'אווה, אבל שני פרויקטים, שתי פריסות, ומימוש עצמי של התחברות וזמן אמת.
- **Firebase**: מסד לא טבלאי; המידע שלנו מלא קשרים והרשאות.
- **ספריית רכיבים מוכנה** (MUI וכדומה): כבדה, וקשה יותר להתאים לעיצוב ולימין־לשמאל. נשקול רכיבים בודדים לפי הצורך.
- **pnpm / yarn**: מהירים יותר, אבל עוד כלי ללמוד בלי תועלת אמיתית בפרויקט בגודל הזה.

## השלכות
- Next.js 16 שונה מהגרסאות שרוב המדריכים ברשת מתארים. התיעוד הנכון לגרסה שלנו נמצא ב־`node_modules/next/dist/docs/` (ראה `AGENTS.md`).
